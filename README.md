
# Greek ESPD Service - Angular Clarity Migration

## Overview

This project was completed as part of my BSc thesis in the Department of Digital Systems at the University of Piraeus in 2024.

The project focused on modernizing the frontend of the Greek national ESPD service (Promitheus ESPDint) by replacing Angular Material components with Angular Clarity equivalents while preserving the application's existing functionality.

The goal was to improve the user interface, introduce additional UI components, and explore how a component-library migration could enhance an existing web application.

## Objectives

- Migrate existing UI components from Angular Material to Angular Clarity
- Preserve the application's existing workflows and functionality
- Introduce additional interface components and usability improvements
- Document the technical context and frontend modernization process

## Key Contributions

- **Frontend migration:** Replaced Angular Material components with Angular Clarity equivalents
- **Custom timeline component:** Implemented a timeline component to support step-by-step navigation
- **Back-to-top button:** Added a navigation utility to help users return to the top of longer pages
- **Improved alerts:** Introduced clearer alerts to communicate unavailable information
- **Searchable country selection:** Improved country selection with searchable, filtered options
